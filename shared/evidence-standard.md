## Recency and citation convention

For a project whose value is being **accurate and up to date**, treat freshness
as part of the evidence, not an afterthought.

- **Date every consequential claim.** State when the source was checked, e.g.
  "(checked 2026-09)". Guidance changes; an undated claim is a stale claim
  waiting to happen.
- **Name the guideline version.** Cite the specific body and version/year, e.g.
  "NICE CG181 (2023 update)" rather than "NICE guidance".
- **Prefer the newest applicable evidence** and note when a source is superseded.
- **Re-verify on use for high-stakes topics.** Screening ages, blood-pressure or
  lipid targets, drug interactions and supplement doses must be checked against
  current guidance at the time of advice — never asserted from memory.
- **Flag likely drift.** If a claim depends on figures that change periodically,
  say so and point the user to the authoritative source for the current value.
- **Applicability by region.** Confirm the guidance matches the user's country
  (see `user-profile.md`); note when US and UK guidance differ.

### Citation format (lightweight)

> Claim. — Source body, document/version, year (checked YYYY-MM). Link if available.

Never invent a paper, DOI, author, quotation, result, consensus **or date
checked**.
